# Evee interface guide

## Direction

Build a calm, capable workspace for managing prospect research and thoughtful outreach. The interface should feel clear and human, with restrained color, confident typography, and useful whitespace. Prefer open layouts and simple dividers over nested panels and decorative cards.

## Foundations

- Light canvas: `#F7F7F5`; raised surface: `#FFFFFF`.
- Dark canvas: `#171916`; raised surface: `#1E211D`.
- Main text: `#20211F`; secondary text: `#777A74`.
- Hairline: `#E8E9E5`; muted green accent: `#4F6653`.
- Use system sans-serif typography, medium weights, and compact, readable headings.
- Buttons and fields use 8px corners. Large surfaces use 12px corners only when a boundary is needed.
- Keep shadows rare. Use border, spacing, and type hierarchy to establish structure.

## Components and language

- Navigation uses sentence case, short labels, and a quiet active state.
- Primary actions use a solid muted green fill. Secondary actions use a thin border.
- Status labels are concise and descriptive; reserve color for state or priority.
- Use plain, task-oriented language for page titles and controls: “Leads,” “Drafts,” “New campaign,” “Import list,” “Review,” and “Save.”
- Avoid internal system names, jargon, release labels, and unnecessary uppercase copy in customer-facing surfaces.
- Support keyboard focus, readable contrast, responsive layouts, and reduced motion.

## Layout

- Align content to a shared centered width with consistent side padding.
- Give page titles and primary actions a clear first row.
- Group related information with whitespace and dividers; use a container only when it improves focus or interaction.
- Keep tables and long workflows readable on small screens, with deliberate overflow behavior.
